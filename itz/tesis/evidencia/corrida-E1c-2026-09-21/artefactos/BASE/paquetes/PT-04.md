## Observaciones de la revisión

- **mayor** (criterio_aceptacion) `frontend/src/styles.css:1`: Tailwind se usa con `@tailwind base/components/utilities`, pero el build `@angular-devkit/build-angular:application` (Angular 18) solo procesa Tailwind si hay configuración PostCSS (`.postcssrc.json` o `postcss.config.js`) o si se usa el soporte automático detectando `tailwind.config.js`. Angular 18 detecta tailwind.config.js automáticamente, pero `postcss` y `autoprefixer` en devDependencies sin config explícita generan ambigüedad; el PR no ha sido compilado por el autor, por lo que el layout con clases Tailwind puede no aplicarse.
- **mayor** (criterio_aceptacion) `frontend/src/app/core/config/api-base-url.ts:30`: La arquitectura pide que API_BASE_URL se inyecte en runtime (nginx.conf.template/config.json) y el código lee `window.__APP_CONFIG__`, pero nada en el PR carga ese objeto: `index.html` no incluye ningún `<script src="/config.js">`. Con `environment.ts` de producción en '' el runtime config nunca se aplicaría en despliegue.
- **mayor** (buenas_practicas) `frontend/angular.json:31`: La configuración `production` (por defecto) usa `environment.ts` con apiBaseUrl '' y `development` reemplaza por `environment.development.ts`; es coherente, pero el target `test` no existe y `lint` con `@angular-eslint/builder` requiere `.eslintrc.json` con `parserOptions.project` no definido; `plugin:@angular-eslint/template/process-inline-templates` requiere el plugin `@angular-eslint/template` listado en overrides de *.ts, no está declarado en `plugins` de ese override. Puede fallar `ng lint`.
- **menor** (pruebas) `frontend/src/app/core/config/api-base-url.spec.ts:45`: La prueba 'cae al valor del environment' solo verifica `typeof === 'string'`, no comprueba el comportamiento.
- **menor** (buenas_practicas) `frontend/src/app/core/config/api-config.service.ts:18`: `isApiUrl` con base vacía devuelve true para cualquier URL que empiece por '/', incluidas rutas de assets locales; y con base no vacía `startsWith` puede coincidir con dominios prefijo (p. ej. http://localhost:8080.evil.com).
- **menor** (buenas_practicas) `frontend/package.json:1`: No hay `package-lock.json` en el PR, pero la arquitectura de CI/Dockerfile usa `npm ci`, que falla sin lockfile.
