# PT-05 — Despliegue: Dockerfiles de producción y CI con GitHub Actions

_BASE: Esqueleto del aplicativo_

Deja el aplicativo desplegable en Cloud Run: backend/Dockerfile multi-stage (maven:3.9-eclipse-temurin-21 y eclipse-temurin:21-jre, puerto 8080, healthcheck /actuator/health) y frontend/Dockerfile multi-stage (node:20-alpine y nginx:alpine, fallback a index.html, /healthz, API_BASE_URL inyectada en runtime vía nginx.conf.template). Workflows de GitHub Actions: en PR, mvn verify en backend y npm ci, lint y jest en frontend; en push a main, docker build, push a Artifact Registry y gcloud run deploy por servicio con Workload Identity Federation, reconstruyendo cada servicio solo si cambian sus rutas. Actualiza el README raíz con la sección de despliegue.
