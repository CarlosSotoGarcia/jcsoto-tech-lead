# PT-02 — Base del backend: Spring Boot, config, Flyway, Swagger y README

_BASE: Esqueleto del aplicativo_

Proyecto Maven Spring Boot 3 / Java 21 con la estructura de paquetes por módulo (config, common, auth, user, passwordreset), application.yml y application-prod.yml con propiedades tipadas (JwtProperties, MailConfig), conexión a PostgreSQL, Flyway con V1__auth.sql (tablas users, roles, user_role, password_reset_token, revoked_token, auth_event y seed inicial de roles/usuario) y ddl-auto=validate. Manejo de errores base con ProblemDetail (@RestControllerAdvice), actuator health y springdoc-openapi con Swagger UI en /swagger-ui.html y /v3/api-docs, con esquema bearerAuth global. Sin lógica de negocio.

## Entregables

- pom.xml con Spring Web, Security, JPA, Validation, Flyway, PostgreSQL, springdoc, MapStruct, Lombok, Actuator, Mail
- InventariosApplication y estructura de paquetes
- application.yml y application-prod.yml con server.port=${PORT}
- V1__auth.sql con esquema y seed
- OpenApiConfig con bearerAuth y Swagger UI accesible

- Prueba de arranque del contexto y test de health con JUnit 5 (Testcontainers o similar)
